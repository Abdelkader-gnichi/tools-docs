# Harbor Registry: Installation & Configuration Guide

This guide details how to install, configure, and manage a self-hosted Harbor image registry. It covers running Harbor in **HTTP mode** locally and exposing it via **HTTPS** using a **zrok** tunnel.

## Prerequisites
*   **Host Machine:** Linux-based OS (Ubuntu/CentOS recommended).
*   **Software:**
    *   [Docker Engine](https://docs.docker.com/engine/install/)
    *   [Docker Compose](https://docs.docker.com/compose/install/)
    *   `curl` and `tar` utilities.

## Server Installation

### 1. Download Harbor
Do not use hardcoded versions. Always fetch the latest stable release.

**Option A: Automatic Download (Recommended)**
Run the following commands to detect the latest version and download the online installer:

```bash
# define the version variable using the GitHub API
HARBOR_VERSION=$(curl -s https://api.github.com/repos/goharbor/harbor/releases/latest | grep '"tag_name":' | sed -E 's/.*"([^"]+)".*/\1/')

echo "Downloading Harbor version: $HARBOR_VERSION"

# Download the installer
curl -L "https://github.com/goharbor/harbor/releases/download/${HARBOR_VERSION}/harbor-online-installer-${HARBOR_VERSION}.tgz" -o harbor-online-installer.tgz
```

**Option B: Manual Download**
Visit the [Harbor Releases Page](https://github.com/goharbor/harbor/releases) and download the `harbor-online-installer-vX.Y.Z.tgz`.

### 2. Extract
```bash
tar xzvf harbor-online-installer*.tgz
cd harbor
```

## Configuration (HTTP Mode)

Before installing, you must configure the `harbor.yml` file.

1.  **Create the configuration file:**
    ```bash
    cp harbor.yml.tmpl harbor.yml
    ```
2.  **Edit the file:**
    ```bash
    vi harbor.yml
    ```
3.  **Required Changes:**
    *   **hostname:** Change `reg.mydomain.com` to your machine's **IPv4 address** (e.g., `192.168.1.50`).
    *   **http:** Ensure port is `80`.
    *   **https:** Comment out the https section if you are handling SSL via zrok, or leave it but ensure we are running on HTTP for the backend.
    *   **harbor_admin_password:** Change the default password (`Harbor12345`) to a secure password.

    **Example Configuration:**
    ```yaml
    hostname: 192.168.xx.xx

    # http related config
    http:
      port: 80

    # https related config (Comment out if using zrok for SSL termination)
    # https:
    #   port: 443
    #   certificate: /your/certificate/path
    #   private_key: /your/private/key/path
    ```

## Running Harbor

1.  **Run the Installer:**
    ```bash
    sudo ./install.sh
    ```
2.  **Verify Status:**
    Check if containers are running:
    ```bash
    sudo docker ps
    ```
    *If containers are not running:*
    ```bash
    sudo docker compose up -d
    ```

## Maintenance: Changing IP Addresses

If the host machine connects to a new network and receives a new IP address, you must update Harbor configuration. **Do not just restart Docker.**

1.  **Stop Harbor:**
    ```bash
    sudo docker compose down -v
    ```
2.  **Update Config:**
    Edit `harbor.yml` and update the `hostname` field with the new IPv4 address.
3.  **Run Prepare Script:**
    This applies the configuration changes to the environment files.
    ```bash
    sudo ./prepare
    ```
4.  **Start Harbor:**
    ```bash
    sudo docker compose up -d
    ```

## Exposing via HTTPS (zrok Tunnel)

To access Harbor securely over the internet without configuring SSL directly on the host, use **zrok**.

1.  **Reserve a Tunnel:**
    Map the tunnel to your local machine's IP on port 80.
    ```bash
    # Syntax: zrok reserve public <HOST_IPV4>:80 --backend-mode proxy
    zrok reserve public 192.168.xx.xx:80 --backend-mode proxy
    ```
    *Copy the specific token generated by this command.*

2.  **Share the Tunnel:**
    ```bash
    zrok share reserved <YOUR_SPECIFIC_TOKEN> --headless
    ```

**Result:** You now have a public HTTPS URL (e.g., `https://fe23-...zrok.io`) pointing to your Harbor instance.

## Client Configuration (Docker Daemon)

Any machine (pusher or puller) connecting to Harbor via **HTTP** (Local LAN) must configure Docker to trust the insecure registry.

### For Linux Clients
1.  Edit or create the daemon config:
    ```bash
    sudo vi /etc/docker/daemon.json
    ```
2.  Add your Harbor host IP:
    ```json
    {
      "insecure-registries": ["192.168.xx.xx:80", "192.168.xx.xx"]
    }
    ```
3.  Restart Docker:
    ```bash
    sudo systemctl restart docker
    ```

### For Docker Desktop (Windows/Mac)
1.  Open Docker Desktop Settings.
2.  Go to **Docker Engine**.
3.  Add the `"insecure-registries"` line inside the JSON block as shown above.
4.  Click **Apply & Restart**.

*(Note: If connecting via the zrok HTTPS URL, this step is usually not required if the zrok certificate is valid, but it is good practice to verify connectivity.)*

## Workflow: Tagging & Pushing Images

**On the "Pusher" Machine:**

1.  **Logout of old sessions:**
    ```bash
    sudo docker logout # Logs out of DockerHub
    # OR specific registry
    sudo docker logout 192.168.xx.old
    ```

2.  **Login to Harbor:**
    *Via Local HTTP:*
    ```bash
    docker login 192.168.xx.xx
    ```
    *Via zrok HTTPS:*
    ```bash
    docker login https://<your-zrok-url>
    ```
    *Provide username (`admin`) and the password you set in `harbor.yml`.*

3.  **Create Project:**
    Log in to the Harbor Web UI (via browser) and create a new **Project** (e.g., `my-project`).

4.  **Tag the Image:**
    Structure: `Host/Project/ImageName:Tag`
    ```bash
    # Syntax
    docker tag <local_image>:<tag> <HARBOR_HOST>/<PROJECT_NAME>/<IMAGE_NAME>:<TAG>

    # Example
    docker tag my-app:latest 192.168.1.50/my-project/my-app:v1
    ```

5.  **Push the Image:**
    ```bash
    docker push 192.168.1.50/my-project/my-app:v1
    ```

## Workflow: Pulling Images

**On the "Client" Machine:**

### Option A: Manual Pull
1.  Ensure Docker daemon is configured (if using HTTP).
2.  Login:
    ```bash
    docker login 192.168.xx.xx
    # OR via zrok
    docker login https://<your-zrok-url>
    ```
3.  Pull:
    ```bash
    docker pull 192.168.xx.xx/my-project/my-app:v1
    ```

### Option B: Docker Compose
Create a `docker-compose.yml` for your deployment:

```yaml
version: '3.8'
services:
  my-app:
    # Use the full path to the image in Harbor
    image: 192.168.xx.xx/my-project/my-app:v1
    ports:
      - "8080:80"
    restart: always
```

Run the deployment:
```bash
docker compose up -d
```
